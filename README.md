.  TJA Gym

Este es el proyecto de nuestra página web del gimnasio TJA. La idea es practicar HTML y montar una web sencilla con varias páginas.

    Qué tiene la web
- index.html → página de inicio  
- content.html → contenidos del gym (cardio, nutricion, etc.)  
- detail.html → detalles de un producto de nuestra proteina
- info.html → información del proyecto  
- Carpeta imagenes con las fotos que usamos

    Cómo verlo
1. Descargas el repo  
2. Abres el `index.html` en el navegador  
3. Y ya puedes moverte por las páginas con el menú
